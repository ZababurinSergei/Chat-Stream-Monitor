## [Unreleased]

## [0.0.11] - 27.07.2026

### Добавлено

- **AiDataTable / AiToolbar** — глобальный поиск: элемент тулбара **search**; строки таблицы фильтруются по совпадению текста (без учёта регистра) в любой видимой колонке, найденный текст подсвечивается в ячейках.
- **AiToolbar** — у элемента тулбара **search** (`itemType: 'input'`) можно задать `placeholder` (по умолчанию «Поиск...»); поле поиска отключается вместе с остальным тулбаром через проп `disabled`.
- **AiDataTable** — контекстное меню строки по клику правой кнопкой мыши с пунктами «Копировать» и «Удалить».

### Изменено

- **AiDataTable** — у последней строки добавлен нижний внутренний отступ (`10px`) для компенсации размера `thumb` у горизонтального `scrollbar`.
- **AiDataTable** — у последней колонки добавлена минимальная ширина (`12px`) для компенсации размера `thumb` у вертикального `scrollbar`.

## [0.0.10] - 15.07.2026

### Добавлено

- **AiDataTable** — в тулбар добавлен dropdown **export** с пунктами «Экспортировать все в Excel» и «Экспортировать выбранные строки в Excel».
- **initGlobalSettings** — в `tableApi` добавлено необязательное поле `export`: функция `({ component, fileName }) => void`, вызывается при выборе пункта dropdown **export** любой таблицы. `component` — адаптер с частью API `dxDataGrid` (`getVisibleColumns`, `option`, `getDataSource`, `totalCount`, `getSelectedRowsData`), `fileName` — значение пропа `title` таблицы. Для пункта «Экспортировать выбранные строки» `component.getDataSource()`/`totalCount()` отдают только отмеченные строки. Если `tableApi.export` не задан, при клике на экспорт выбрасывается ошибка.
- **AiDataTable** — у колонки можно задать `cellTemplate` (имя слота на компоненте таблицы) для кастомного содержимого ячейки; слот получает пропы ячейки (`value`, `displayValue` и др.).

### Изменено

- **AiDataTable** — событие `toolbar-action` для пунктов dropdown-меню тулбара (`settings`, `export`) эмитит **ключ пункта** (`show-grouping`, `export-excel` и т.д.); для кнопок по-прежнему эмитится `id` действия (`refresh`, `add` и т.д.).
- **AiDataTable** — в `toolbarItems` можно передавать элементы типа `dropdown` с массивом `options` (наряду с `button` и `popselect`).
- **AiDataTable** — у колонки выбора строк фиксированная ширина `40px`.

## [0.0.9] - 09.07.2026

### Изменено

- **AiDataTable** — компонент переведён с пропа `meta` на плоские пропсы: вместо `:meta="{ isEditable: true, columns, api, ... }"` передавайте `isEditable`, `columns`, `api` и остальные поля напрямую. **Несовместимое изменение.**
- **AiDataTable** — `viewId` стал необязательным: таблицу можно использовать без сохранения пользовательских настроек.
- **AiDataTable** — добавлена возможность редактирования в режиме виртуального скролла (`pageSize`).
- **AiDataTable** — улучшено изменение ширины колонок: увеличена область захвата разделителя и скорректировано его позиционирование.
- **AiField** — в режиме просмотра длинный текст переносится по словам и при превышении трёх строк обрезается с многоточием.

### Исправлено

- **AiDataTable** — выбор видимых колонок в `column-chooser` больше не рассинхронизируется с фактической видимостью колонок.
- **AiDataTable** — в `column-chooser` нельзя скрыть все колонки: всегда остаётся хотя бы одна.
- **AiDataTable** — в режиме виртуального скролла локальные несохранённые изменения корректно применяются к подгружаемым данным.
- **HeaderCell** — улучшена читаемость длинных описаний фильтра по дате в заголовке колонки.

## [0.0.8] - 03.07.2026

### Добавлено

- **AiDataTable** — при ошибке сохранения сообщения валидации с сервера (`validationErrors`) показываются в ячейках: красная подсветка, индикатор и подсказка при наведении; ошибка снимается при редактировании поля.
- **AiDataTable** — при заданном `meta.pageSize` включается режим виртуального скролла с подкачкой данных: фиксированная высота строк, длинный текст в нередактируемых ячейках обрезается с многоточием; редактирование в этом режиме недоступно.
- **AiDataTable** — нижняя граница у последней строки.
- **AiDataTable** — `meta.toolbarItems` для добавления своих кнопок в тулбар; по клику эмитится `toolbar-action` с `id` кнопки.
- **AiDataTable** — через ref на компонент доступны `focusedRowKey`, `checkedRowKeys` и `refreshData()` для программного управления таблицей.
- **AiDataTable** — сохранение и восстановление пользовательских настроек: порядок, видимость и ширина колонок, режим автосохранения, видимость области группировки, сфокусированная строка; настройки загружаются при открытии таблицы.
- **AiDataTable** — автосохранение настроек таблицы: чекбокс «Автоматически сохранять настройки» в меню настроек тулбара; при включении изменения колонок, фокуса строки и видимости группировки сохраняются на сервер с задержкой 500 мс; пункт «Сохранить настройки» недоступен, пока автосохранение включено; переключение чекбокса сохраняется сразу.
- **AiDataTable** — изменение порядка колонок перетаскиванием заголовка.
- **FilterSelect / DateFilter** — программное открытие `DateFilter` по клику на область `Выберите фильтр`.

### Изменено

- **FilterCell** — опции булевого фильтра заменены с `True`/`False` на «Да»/«Нет».
- **AiDataTable** — приоритет подсветки ячеек: ошибка валидации → изменённое значение → выделенная или сфокусированная строка.
- **AiDataTable** — режим автосохранения настроек по умолчанию включён (ранее был выключен).
- **AiDataTable** — в `meta.api` передаются строковые пути эндпоинтов (`get`, `set`), а не функции; HTTP-запросы настраиваются один раз при старте приложения через `initGlobalSettings`. **Несовместимое изменение.**
- **AiDataTable** — редактор `selector` в колонках загружает справочник через тот же глобальный `tableApi`, что и таблица; в `editor.api` указывается строка эндпоинта.
- **AiCell** — ошибка ячейки задаётся пропом `validationErrorMessage`; проп `isValidationError` удалён. **Несовместимое изменение.**
- **AiDataTable / AiToolbar** — в `meta.toolbarItems` поле `elementType` переименовано в `itemType`. **Несовместимое изменение.**
- **AiField** — пустое текстовое поле при сохранении передаётся как `null`, а не пустая строка.
- **Тема** — обновлены оттенки подсветки ошибок, границы таблицы, тулбара и футера; у элементов интерфейса скругления по умолчанию — `0px`.
- **AiDataTable** — в `meta` добавлено обязательное поле `viewId` — идентификатор таблицы для сохранения настроек. **Несовместимое изменение.**
- **initGlobalSettings** — в `tableApi` добавлен `userSettingsApi` с путями эндпоинтов `get` и `set`; `userChanges` используется для загрузки и сохранения настроек таблицы; при неполной конфигурации инициализация завершается ошибкой. **Несовместимое изменение.**

### Исправлено

- **AiDataTable** — несохранённые изменения в других строках больше не теряются при удалении строк.
- **AiDataTable** — корректно удаляются несохранённые новые строки.
